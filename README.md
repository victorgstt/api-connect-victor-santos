# API Connect

## Propósito do Sistema
A API Connect é um Produto Mínimo Viável (MVP) desenvolvido com o objetivo de fornecer uma solução de back-end robusta e estruturada em camadas para o gerenciamento de usuários. O sistema adota os princípios da arquitetura REST e do padrão MVC (Model-View-Controller), garantindo alta separação de responsabilidades, validações rigorosas de dados de entrada e códigos de status HTTP semânticos.

## Tecnologias Empregadas
* **Node.js**: Ambiente de execução JavaScript assíncrono de alta performance.
* **Express**: Microframework web para gerenciamento de rotas e middlewares.
* **JavaScript (ES6+)**: Linguagem principal utilizada no desenvolvimento da lógica de negócio.
